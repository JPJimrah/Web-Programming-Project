About Me

Professional Background

My name is Jimrah Peter Jimrah, a future Computer Engineer and final-year student at Ahmadu Bello University, Zaria. My professional direction is shaped by a desire to build dependable technology that addresses practical needs in everyday life.

I am passionate about web programming because it combines logical problem-solving with the design of useful, accessible experiences. Through HTML, CSS, and software development practice, I am learning how to create clear interfaces and dependable web systems.

Hardware and Software Integration

My interest in hardware-software integration connects my web programming studies with my work in robotics and embedded systems. I enjoy exploring how sensors, microprocessors, motors, and communication modules can work together with software to produce responsive systems.

My current Autonomous Delivery Robot project reflects this interest. It brings together Arduino programming, sensor integration, obstacle avoidance, motors, trays, and Bluetooth mobile control in one practical system.

Computer Systems and Future Goals

I am also developing a broad understanding of computer systems, including Linux, C programming, MATLAB, microprocessor systems, and software engineering. These areas help me understand computers from both the physical and software perspectives.

As I progress toward graduation, I hope to contribute to engineering teams that create reliable embedded, robotic, and software solutions. I also value continuous learning, technical writing, project planning, and mentoring others.
